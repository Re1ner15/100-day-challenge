# RIR Cheat-Sheet — "Is this weight right?"

**RIR = Reps In Reserve** = how many more reps you *could* have done with good form after finishing your set.

## After your set, ask: how many more could I have done?

| Could've done... | Verdict | Do this |
|------------------|---------|---------|
| **4+ more** (felt light) | ❌ Too light | Go up next set / next time |
| **2–3 more** (hard, smooth) | ✅ **PERFECT** | This is your weight |
| **0–1 more** (grinding, form slipping) | ⚠️ Too heavy | Drop down |
| **Missed the target reps** | ❌ Way too heavy | Drop down now |

## Rules
- **"Enough" = you hit the target reps with ~2–3 solid reps left in the tank.**
- **Don't train to failure.** Leaving 2–3 reps is correct — in a deficit it protects recovery and joints.
- **Form is the hard stop.** The moment form breaks (back rounds, swinging, cheating) the set is over — that rep doesn't count.

## Gut-check
- Reps 1–8 all feel identical and easy → **too light**.
- Last 1–2 reps slow down but you don't hit a wall → **just right**.
- Rep 5 of an 8-rep set is already a struggle → **too heavy**.

## Don't know how to track it? Just log ONE WORD.
After your top (heaviest) set, write one of these instead of a number:

| Log this word | What it felt like | = RIR | Meaning for next time |
|---------------|-------------------|-------|-----------------------|
| **EASY** | could've done 4+ more, bar flew up | 4+ | go heavier / add reps |
| **GOOD** | hard but the last rep was smooth | 2–3 | ✅ perfect — keep it, chase reps |
| **HARD** | last rep slowed right down, barely made it | 1 | hold here, don't add yet |
| **MAX** | last rep was a grind / form slipped | 0 | too heavy — drop a little |

**How to feel it in the moment:** on your final rep, notice the **bar speed**. If it moved fast = EASY. If it slowed but finished clean = GOOD. If it crawled = HARD. If it stalled/you cheated = MAX. That's all "RIR" really is — bar speed on the last rep.

So in your workout log, a set is just: `weight × reps — GOOD`. That one word tells me everything I need to set next week.
