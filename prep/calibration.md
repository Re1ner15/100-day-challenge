# Prep Week — Calibration (Mon 31 Aug – Sun 6 Sep · NOT counted in the 100 days)

**Goal this week:** find the REAL weight for each exercise. No progression, no ego. You're taking measurements. The 100-day program starts the following Monday (7 Sep) using these numbers.

## The rule: find weights by feel (RIR)
For the pyramid, each set has a rep target and a target "reps in reserve" (RIR = how many more you *could* have done):

| Set | Reps | Target RIR | Means |
|-----|------|-----------|-------|
| 1 | 12 | 2–3 left | comfortably hard |
| 2 | 10 | ~2 left | hard |
| 3 | 8 | 1–2 left | heaviest, still clean form |

## How to run each exercise (Week 1)
1. Warm up the movement (1–2 light sets, don't count these).
2. **Set 1:** pick a weight you're fairly sure you can do 12 times. Do 12. Ask: *how many more could I have done?*
   - More than 3 left → too light. Go heavier on Set 2 (and note "start higher next week").
   - Couldn't reach 12 → too heavy. Note it, drop down.
3. **Set 2:** add a small step (one DB size / one plate step / +2.5–5 kg). Do 10. Aim ~2 left.
4. **Set 3:** add another step. Do 8. Aim 1–2 left, **form stays clean**.
5. **Write down what you actually did** — weight, reps, and RIR — below.

Typical jump between sets is roughly one increment (a DB size, or 2.5–5 kg/side). Whatever lands you in the RIR targets is *correct* — there's no wrong number.
