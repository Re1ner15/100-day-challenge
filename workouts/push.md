# PUSH — Wed (~14 sessions)

## Set scheme (your pyramid)
3 sets per exercise, **weight up / reps down**:

| Set | Target reps | Load |
|-----|-------------|------|
| 1 | 12 | lightest |
| 2 | 10 | middle |
| 3 | 8 | heaviest |

Keep **≥2 reps in reserve (RIR)** on every set. In a deficit, grinding to failure costs more than it gives.

## Baseline loads
Calibrated in the **prep week** — you'll find these in the gym. See [`../prep/calibration.md`](../prep/calibration.md). Your rough starting guesses (from memory) are below; confirm or correct them during calibration. Barbell = **kg per side, not counting the bar**. DBs = **per hand**.

| Exercise | Reps (S1/S2/S3) | Set 1 | Set 2 | Set 3 |
|----------|-----------------|-------|-------|-------|
| Barbell Flat Chest Press | 12/10/8 | ~10 /side | ~15 /side | ~17.5 /side |
| Incline DB Chest Press | 12/10/8 | ~10 | ~12.5 | ~15 |
| Chest Fly | 12/12/10 | calibrate | calibrate | calibrate |
| Barbell Shoulder Press | 12/10/8 | bar only | +5 /side | +7.5 /side |
| Side Raise (DB) | 15/12/12 | ~7.5 | ~10 | ~12.5 |
| Tricep Pushdown | 12/12/10 | calibrate | calibrate | calibrate |
| Seated Dips | 12/10/8 | calibrate | calibrate | calibrate |

> **Shoulder press note:** tight traps limit loading here — that's fine. We progress this one on **reps only**, not weight. No pressure to add plates.

## How we progress (deficit double-progression)
**Prep week (NOT counted) — Calibration:** find real weights (see calibration sheet). No progression.

**Phase A — Weeks 1–7 (rep-build):** Keep the calibrated loads. Each week, try to add **1 rep to any set you can** beyond the 12/10/8 target, up to a stretch cap of **15 / 13 / 11**. Weight stays put; reps climb. Holding is a valid week.

**Deload — Week 8:** 2 sets only, ~60% effort. Recover.

**Phase B — Weeks 9–14 (load-test):** For any lift where you hit the **15/13/11 cap two weeks running** with ≥2 RIR → add load (barbell **+2.5/side**, DB **next size up**) and reset reps to **12/10/8**. Everything else keeps rep-building.

**Override:** low-energy / bad-sleep week → repeat last week, don't force. In a cut that IS the plan working.
