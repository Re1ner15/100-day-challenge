| Set | Target reps | Load |

## How we progress (deficit double-progression)
**Prep week (NOT counted) — Calibration:** find real weights (see calibration sheet). No progression.

**Phase A — Weeks 1–7 (rep-build):** Keep the calibrated loads. Each week, try to add **1 rep to any set you can** beyond the 12/10/8 target, up to a stretch cap of **15 / 13 / 11**. Weight stays put; reps climb. Holding is a valid week.

**Deload — Week 8:** 2 sets only, ~60% effort. Recover.

**Phase B — Weeks 9–14 (load-test):** For any lift where you hit the **15/13/11 cap two weeks running** with ≥2 RIR → add load (barbell **+2.5/side**, DB **next size up**) and reset reps to **12/10/8**. Everything else keeps rep-building.

**Override:** low-energy / bad-sleep week → repeat last week, don't force. In a cut that IS the plan working.
